# trang-trai-m-farm
Trang trại M Farm — Nuôi con gì? Trồng cây gì? Nhận nuôi theo mã QR.

Task: [issue #1](https://github.com/huynguyen2812/trang-trai-m-farm/issues/1).

Bản chạy thử web nằm ở `web/`.
- Cửa ngoài: quảng cáo, chợ suất, nhật ký một mã khi quét QR — không cần login.
- Cửa trong: vườn nhà. Tài khoản = SĐT trên hợp đồng + mã Zalo. Google là chìa phụ.

Mở `web/index.html` trên máy. Ghi chép ở `docs/dang-nhap.md`.
Giá trên bản này là số mẫu, chưa phải giá trại.
